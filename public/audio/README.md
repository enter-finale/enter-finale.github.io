# 音声素材の置き場所

ここに以下のファイル名で WAV（または MP3 / OGG / M4A など `decodeAudioData` が読める形式。ファイル名は `src/config.ts` の `SAMPLE_FILES` で変更可）を置くと、アプリ起動時に自動で読み込まれます。
ファイルが無い／読み込めない場合は Web Audio API の合成音に自動フォールバックします。

| ファイル名 | 用途 | 推奨 |
|---|---|---|
| `snare-1.wav` | タイピング中のスネア A | 0.3〜1 秒、単発。B と 1 打ごとに交互に鳴る |
| `snare-2.wav` | タイピング中のスネア B | 同上。A と少し違うニュアンスだと連打が機械的にならない |
| `tom-high.wav` | ハイタム | 0.5〜1.5 秒 |
| `tom-low.wav` | ロータム | 0.6〜1.5 秒 |
| `enter.wav` | Enter で鳴る「ジャーン」 | 3〜8 秒、余韻込み。キック・クラッシュ・ギターを 1 本にまとめた音。先頭にアタックを置く |
| `crowd-cheer.wav` | 観客の歓声 | 8〜15 秒。アプリ側で 0.3 秒フェードインする。長いと読み込みが重くなるので 1MB 前後が目安 |

- サンプルレートは 44.1kHz / 48kHz どちらでも可（AudioContext に合わせてデコードされます）
- モノラル / ステレオどちらでも可
- ピークは -1 dBFS 程度に揃えると、設定パネルのゲイン初期値のままでバランスが取れます
- 打鍵用の音（スネア・タム）は先頭の無音を詰めておくと打鍵と音がぴったり合います（先頭に 100ms の無音があると、その分だけ遅れて聞こえます）
- 不要になったら削除するだけで合成音に戻ります
