# 音声素材の置き場所

ここに以下のファイル名で WAV（または MP3 / OGG / M4A など `decodeAudioData` が読める形式。ファイル名は `src/config.ts` の `SAMPLE_FILES` で変更可）を置くと、アプリ起動時に自動で読み込まれます。
ファイルが無い／読み込めない場合は Web Audio API の合成音に自動フォールバックします。

| ファイル名 | 用途 | 推奨 |
|---|---|---|
| `snare.wav` | タイピング中のスネア | 0.3〜0.6 秒、単発 |
| `tom-high.wav` | ハイタム | 0.4〜0.8 秒 |
| `tom-mid.wav` | ミッドタム | 0.5〜0.9 秒 |
| `tom-low.wav` | フロアタム | 0.6〜1.2 秒 |
| `kick.wav` | フィナーレのキック | 0.5〜1 秒 |
| `crash.wav` | フィナーレのクラッシュ | 2〜4 秒、余韻込み |
| `guitar-sustain.wav` | タイピング中にループするギターのサステイン | 2〜6 秒。**先頭と末尾が自然につながるループ素材**にしてください（ゼロクロスで切る、または DAW でループ書き出し） |
| `guitar-finale.wav` | Enter で鳴るパワーコード | 5〜10 秒、余韻込み |
| `crowd-cheer.wav` | 観客の歓声 | 6〜12 秒。先頭で急に立ち上がらず、アプリ側で 0.45 秒フェードインします |

- サンプルレートは 44.1kHz / 48kHz どちらでも可（AudioContext に合わせてデコードされます）
- モノラル / ステレオどちらでも可
- ピークは -1 dBFS 程度に揃えると、設定パネルのゲイン初期値のままでバランスが取れます
- 不要になったら削除するだけで合成音に戻ります
